# 执行计划

## TDD 规范
每个任务执行务必严格遵循TDD规范：
1. 写测试用例（引用尚不存在的类/方法），创建最小桩代码（空类、返回 null/default 的方法）→ 让测试能 **编译通过**
2. 运行测试 → 测试 **执行失败**（断言不通过）
3. 实现业务逻辑
4. 运行测试 → 测试通过 →  🟢 GREEN
5. 重构
