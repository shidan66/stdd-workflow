# STDD: 编码实现

## 目标

按 plan.md 的执行计划，依次完成每个任务。

## 前提

- 已完成 `/stdd:plan` 阶段
- plan.md 包含执行计划

## 执行步骤

1. **触发 tdd 技能**：加载并使用 test-driven-development 技能

2. **读取 plan.md**：获取执行计划

3. **按顺序执行任务**：对于每个任务：
   - 标记任务开始
   - 编写测试用例
   - 运行测试（预期失败）
   - 编写实现代码
   - 运行测试（预期通过）
   - 重构（如需要）
   - 标记任务完成

4. **处理任务间依赖**：
   - 如果后续任务依赖前置任务的产出，先完成前置任务
   - 如果遇到问题，记录并继续处理下一个独立任务

5. **更新 tasks.md**：标记已完成的任务

## 输出

- 代码文件（实现代码）
- 测试文件（测试用例）
- 更新的 tasks.md（标记完成的任务）
- 告诉用户可以进入 `/stdd:verify` 阶段
