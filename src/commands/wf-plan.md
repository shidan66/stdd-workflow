# WF: 执行计划

## 目标

基于任务清单，整理执行顺序、依赖关系、串并行安排。

## 前提

- 已完成 `/wf:split` 阶段
- tasks.md 包含原子任务清单

## 执行步骤

1. **触发 writing-plans 技能**：加载并使用 writing-plans 技能

2. **读取 tasks.md**：获取任务清单

3. **分析依赖**：识别任务间的依赖关系

4. **规划执行顺序**：
   - 确定哪些任务可以并行执行
   - 确定哪些任务必须串行执行
   - 识别关键路径

5. **按 TDD 规范落地**：确保每个任务都遵循 TDD 流程：
   - 先写测试
   - 再写实现
   - 重构

6. **写入 plan.md**：将执行计划写入 plan.md，格式：
```markdown
# 执行计划

## 任务依赖图

## 执行顺序

### 阶段1: [可并行任务]
- [ ] Task 1
- [ ] Task 2

### 阶段2: [依赖阶段1的任务]
- [ ] Task 3 (依赖 Task 1)

## TDD 规范
每个任务执行流程：
1. 写测试用例
2. 运行测试（预期失败）
3. 写实现代码
4. 运行测试（预期通过）
5. 重构
```

## 输出

- plan.md（执行计划）
- 告诉用户可以进入 `/wf:apply` 阶段
